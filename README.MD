# SocialBook Interface

A static social-feed interface inspired by familiar social networking layouts, built with HTML, CSS, and JavaScript.

## Highlights

- Feed-style layout with profile, post, and navigation imagery
- Dark-mode interaction in the front-end
- Local image assets included in the repository

## Run locally

Open `index.html` in a modern browser. No package installation or build step is required.

## Project files

- `index.html` — page structure
- `styles.css` — layout and styling
- PNG assets — feed content and interface imagery

## Scope

This is a front-end interface exercise. It does not include authentication, a backend, or real social-network functionality.
